OndoREui: Ondo Real Estate consumer-facing UI

Next.js 15 App Router static export (GitHub Pages behind Cloudflare), TypeScript, Tailwind CSS with design tokens.

All rules for working in this repo are in AGENTS.md (the single source of truth). Read it first. Quick commands: npm run dev (:3000), npm run lint, npm run test:run, npm run check:links. Env variables: .env.example.
